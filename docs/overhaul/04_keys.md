# Keys (authoritative)

Default bindings as they change through the overhaul. Phase 13 makes every
one rebindable; until then these are fixed. When a phase adds or moves a
key it also updates the Controls panel (F2) and the top-level README.

Context decides what a key does. Order of precedence for E, R, X and F: an
open panel, then being held (grabbed), then the nearest thing in reach
(door, window, furniture, person, vehicle, station), then the selected belt
item.

on the whole stack, A/D or Left/Right changes column or tab, Esc closes.
